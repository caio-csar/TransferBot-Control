# TransferBot Control

Repositório público usado exclusivamente para o controle remoto do **TransferBot**.

## Kill switch

O arquivo `status.json` é consultado pelo TransferBot antes de executar transferências.

- `enabled: true` — transferências liberadas.
- `enabled: false` — transferências bloqueadas remotamente.

> **Importante:** este repositório é público. Não adicione credenciais, tokens, senhas, endpoints privados ou código-fonte do TransferBot.

O código-fonte e a documentação técnica detalhada ficam no repositório privado `caio-csar/TransferBot`.
